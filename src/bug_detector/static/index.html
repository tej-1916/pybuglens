About PyBugLens

AI-Powered Python Code Intelligence. Find bugs. Understand code. Build better Python.

🛡️ Zero-Trust Code Execution Invariant

PyBugLens operates under a mathematically verified zero-execution guarantee: user-submitted Python code is never evaluated, imported, or run via subprocesses. Code is strictly compiled into an Abstract Syntax Tree via ast.parse() and inspected deterministically.
